# Custom feeds for the GL.iNet GL-X3000 image build.
#
# One line per package layer to symlink under ./feeds-local/. Format:
#
#     <symlink-name> <git-url> <ref> <subdir-inside-repo>
#
# `<symlink-name>` is what feeds-local/ ends up calling the package — has to
# be a legal feed identifier (\w+), so dashes get replaced with underscores
# in feed names, but the symlink itself can keep dashes.
#
# `<ref>` can be a tag, branch, or commit SHA. Commits are recommended for
# reproducible builds — branch names track HEAD and will pull new code on
# every prepare.sh run.
#
# Lines starting with '#' and blank lines are ignored.

# adb client (nmeum/android-tools port) with the bInterfaceNumber claim
# patch needed for the RM520N's non-contiguous USB interface descriptors.
android-tools           https://github.com/vjt/openwrt-android-tools.git           master  openwrt/android-tools

# Brotli 1.1.0 — not in 25.12 feeds, required by android-tools.
brotli                  https://github.com/vjt/openwrt-android-tools.git           master  openwrt/brotli

# qfirehose 1.4.17 (vjt fork). Upstream Quectel 1.4.11 bricks RM520N.
qfirehose               https://github.com/vjt/qfirehose.git                       master  openwrt/qfirehose

# Lua AT helpers (5g-info, 5g-monitor, …) + 5g-led-bars procd daemon
# driving the panel signal LEDs from PCC RSRP + mbim-watchdog C daemon
# that watches MBIM Connect indications and reissues `ifup` on PDN
# deactivation. See https://github.com/vjt/quectel-5g-tools.
quectel-5g-tools        https://github.com/vjt/quectel-5g-tools.git                master  openwrt/quectel-5g-tools

# Prometheus collector for Wi-Fi dethrash detection across the fleet.
wifi-dethrash-collector https://github.com/vjt/openwrt-dethrash.git                master  openwrt/wifi-dethrash-collector

# Fantastic Packages: the two base packages that wire their binary repo into
# apk on the router - the developer keyring, and the installer that appends
# the repo lines to /etc/apk/repositories.d/customfeeds.list. Both live at
# the root of their own repo, hence subdir ".".
#
# The fantastic-packages/packages superproject is deliberately NOT used here.
# Every package in it is a git submodule (its .gitmodules lists ~40), and
# prepare.sh clones without --recurse-submodules, so that tree would come
# through as empty directories. Pulling 40 extra repos on every prepare run
# would also not buy anything: the whole catalogue is installable from the
# binary repo once these two are in the image.
fantastic-keyring        https://github.com/fantastic-packages/fantastic-keyring.git         master  .
fantastic-packages-feeds https://github.com/fantastic-packages/fantastic-packages-feeds.git  master  .

# Argon LuCI theme. Not in the OpenWrt 25.12 luci feed, which carries only
# bootstrap, footstrap, material, openwrt and openwrt-2020 — checked against
# themes/ on the openwrt-25.12 branch, not assumed. Upstream maintains only
# `master`, so the tag is the pin: v2.4.7 rather than a branch, because this
# one decides what the web UI looks like and a prepare.sh run should not
# change that underneath you. The Makefile sits at the repo root, hence ".".
luci-theme-argon        https://github.com/jerrykuku/luci-theme-argon.git           v2.4.7  .
