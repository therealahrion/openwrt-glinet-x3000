# Custom feeds for the GL.iNet GL-X3000 image build.
#
# One line per package layer to symlink under ./feeds-local/. Format:
#
#     <symlink-name> <git-url> <ref> <subdir-inside-repo>
#
# `<symlink-name>` is what feeds-local/ ends up calling the package — has to
# be a legal feed identifier (\w+), so dashes get replaced with underscores
# in feed names, but the symlink itself can keep dashes.
#
# `<ref>` can be a tag, branch, or commit SHA. Commits are recommended for
# reproducible builds — branch names track HEAD and will pull new code on
# every prepare.sh run.
#
# Lines starting with '#' and blank lines are ignored.

# NOTE: this build uses the QModem stack (see feeds.conf) for the modem,
# so three of vjt's ModemManager-era custom feeds are intentionally gone:
#
#   * android-tools (adb/fastboot) — OpenWrt 25.12 added its own base
#     `adb` package (package/utils/adb), which collides with vjt's
#     android-tools `adb` and makes the build fail the library-dependency
#     check. adb is only for shelling into the modem's internal SoC — it's
#     not part of the pcie_mhi data path — so it's dropped rather than
#     force-overridden. To add it back later, override base adb via
#     `scripts/feeds install -f` or rename vjt's package.
#   * brotli — only existed to satisfy android-tools; gone with it. (The
#     curl `--without-brotli` patch is dropped too: nothing pulls brotli
#     into staging any more, so curl can't autodetect it.)
#   * qfirehose — QModem ships its own qfirehose (1.4.21, newer than vjt's
#     1.4.17 and integrated with luci-app-qmodem's flash flow), so we let
#     the QModem feed provide it instead of vjt's fork.

# PCIe /dev/mhi_DUN, so the two coexist. Patched at prepare time (0003)
# to drop its ModemManager dependency. See https://github.com/vjt/quectel-5g-tools.
